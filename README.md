# Dinamik Hedef Merkezleme ve Takip Sistemi
Bu projede Python, OpenCV ve YOLOv8 kullanarak hareketli bir videodaki araçları tespit ettim. 
Tespit edilen araçların merkez koordinatlarını matematiksel olarak hesaplayıp ekrana dinamik bir hedef artısı (crosshair) çizdirdim.

**Kullanılan Teknolojiler:**
* Python
* OpenCV (Görüntü İşleme)
* YOLOv8 Nano (Yapay Zeka Destekli Nesne Tespiti)# yolov8-target-tracking-basic
Target lock-on system using YOLOv8 and OpenCV entry-level
